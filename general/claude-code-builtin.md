# Claude Code 내장 스킬

설치 불필요. Claude Code에 포함되어 제공되며 URL이 없다. 버전·환경에 따라 목록이 다를 수 있다.

### code-review
- 종류: 내장 스킬
- 요약: 현재 diff·PR·브랜치를 정확성 버그 위주로 리뷰. 강도(low~max, ultra) 선택, --comment로 PR 인라인 코멘트, --fix로 수정 적용.
- 호출/출처: /code-review
- 설치: 설치 불필요(내장)

### simplify
- 종류: 내장 스킬
- 요약: 변경된 코드의 재사용·단순화·효율 정리를 찾아 바로 적용(버그 탐색은 하지 않음).
- 호출/출처: /simplify
- 설치: 설치 불필요(내장)

### security-review
- 종류: 내장 스킬
- 요약: 현재 브랜치의 변경 사항에 대한 보안 점검.
- 호출/출처: /security-review
- 설치: 설치 불필요(내장)

### init
- 종류: 내장 스킬
- 요약: 코드베이스를 분석해 CLAUDE.md 초기 문서를 생성.
- 호출/출처: /init
- 설치: 설치 불필요(내장)

### loop
- 종류: 내장 스킬
- 요약: 프롬프트나 슬래시 명령을 주기적으로 반복 실행(간격 생략 시 모델이 자체 간격 결정).
- 호출/출처: /loop 5m /명령
- 설치: 설치 불필요(내장)

### schedule
- 종류: 내장 스킬
- 요약: 크론 일정으로 도는 클라우드 에이전트(루틴)를 만들고 조회·수정·실행. 일회성 예약도 가능.
- 호출/출처: /schedule
- 설치: 설치 불필요(내장)

### update-config

- 호출/출처: /update-config
- 설치: 설치 불필요(내장)

- 호출/출처: /fewer-permission-prompts

- 설치: 설치 불필요(내장)
