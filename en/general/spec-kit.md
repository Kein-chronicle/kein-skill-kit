# GitHub Spec Kit — spec-driven development skills

Source: https://github.com/github/spec-kit (MIT). Generated into a project by `specify init`; each skill works in a project that has the `.specify/` structure. The order below is the usual flow.

- Source: https://github.com/github/spec-kit

- When to use: A step in the spec-driven development (SDD) flow
